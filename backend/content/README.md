# Content

Every word on the site lives here. Edit these files — no code changes needed.
The shapes match `frontend/src/api/types.ts`.

| File | Section |
|---|---|
| site.json | Her name, birthday date, hero lines, music |
| journey.json | Our Journey timeline |
| album.json | Photo album chapters |
| reasons.json | Reasons I love you |
| letter.json | The letter |
| gift.json | Gift reveal (sealed until the birthday) |
| london.json | London trip (sealed until the birthday) |
| wishes.json | Messages from family & friends |
| future.json | Our Forever + closing photo |
| settings.json | When sealed sections open |

Photo paths are relative to `backend/media/`, e.g. `"album/beginning/01.webp"`.
